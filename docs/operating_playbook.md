# 每日跑模与风控手册

## 1. 每日流程

先按 `analysis_workflow_v2.md` 获取数据。尤其是最后一轮，必须先确认积分、净胜球、是否已锁定目标，再录入盘口。

赛前一天先跑 `早盘版`。这一版主要看球队强度、联赛画像、初盘和基础伤停，用来形成初始唯一比分。

比赛日前 6 小时跑 `临场版`。更新即时赔率、关键伤停、赛程密度、天气和战意，观察唯一比分是否切换。

首发公布后跑 `终版`。如果首发导致主客预期进球变化超过 `0.18`，或者最终比分从一个总球层跳到另一个总球层，就标记为临场重算场。

赛后跑 `结算版`。记录唯一比分是否命中、总球层是否命中、方向是否命中、赔率错价是否真实存在。

## 2. 输出格式

公开输出只保留三项：

```text
比赛：主队 vs 客队
唯一比分：1-3
信号等级：B
```

内部输出保留复盘字段：

```text
总球层冠军：T=0..10 每层一个
真实概率：模型对最终比分的真实概率
市场概率：赔率反推概率
错价倍数：真实概率 / 市场概率
结构理由：为什么这个比分讲得通
风险点：和盘口、总球、阵容是否存在冲突
```

## 3. 信号等级

`A`：真实概率高，层冠军优势明显，市场冲突低。适合进入重点观察池。

`B`：结构清楚，概率和错价都不错，但层冠军优势没有完全拉开。

`C+`：概率未必高，但错价比较明显，常见于非常规比分。

`C`：只代表模型必须给出一个唯一比分，不代表强信号。

## 4. 数据质量要求

最低可运行数据：

- 联赛平均进球
- 主客队攻防强度
- 主客队近期 xG 或进失球替代指标
- 1X2 或市场预期主客进球

专业推荐数据：

- 精准比分赔率快照
- 大小球和让球盘口
- 官方积分形势、净胜球、平局是否够用
- 资金热度、深盘诱导风险
- 伤停、首发、轮换
- 赛程密度、旅行距离
- 天气、裁判
- 联赛红牌率和平局率

如果某场比赛缺少精准比分赔率，市场错价权重应降低。如果缺少伤停和首发，冷门穿透加成应降低。

## 5. 风控规则

模型可以报非常规比分，但必须过四道闸：

- `情景闸`：先判断这场更像正路、平局、冷门还是乱战，不能为了反大众而反。
- `概率闸`：真实概率不能低到只剩极端赔率幻想。
- `结构闸`：强弱差、伤停、节奏或战意至少有一个解释。
- `冲突闸`：如果和 1X2 强方向严重冲突，必须有足够高的精准比分错价支撑。

连续回测中，如果某类非常规比分连续亏损或连续低命中，应降低该类别的 `cold_bonus`。如果舒服比分长期被过度压低，应恢复其基础权重。

## 6. 数据库建议

生产库建议保留以下表：

- `leagues`：联赛画像和市场可信度。
- `teams`：球队基础信息。
- `matches`：赛程和赛果。
- `team_ratings`：攻防强度、主客场强度、风格参数。
- `odds_snapshots`：赔率快照，按时间记录。
- `match_features`：模型赛前特征。
- `score_candidates`：28 个候选比分的赛前评分。
- `final_picks`：每场唯一比分输出。
- `settlements`：赛后结算和回测指标。
