# 新手使用方法：一次分析12场

你现在不用看命令，也不用改 JSON。

## 最简单用法

1. 回到桌面。
2. 双击 `足球比分模型`。
3. 打开窗口后，会看到 12 行比赛。
4. 把每一行的 `主队`、`客队` 改成真实球队。
5. 不会填的数字先不要动。
6. 点击 `分析12场`。
7. 看结果里的 `唯一比分`。

## 每一行数字怎么理解

| 字段 | 简单理解 |
| --- | --- |
| `主攻` | 主队进攻，`1.00` 普通，`1.20` 偏强，`0.80` 偏弱 |
| `客攻` | 客队进攻，`1.00` 普通，`1.20` 偏强，`0.80` 偏弱 |
| `主防压` | 主队防守压力，越高越容易丢球 |
| `客防压` | 客队防守压力，越高越容易丢球 |
| `主伤停` | 主队伤停影响，`0` 没影响，`0.30` 明显，`0.60` 严重 |
| `客伤停` | 客队伤停影响，`0` 没影响，`0.30` 明显，`0.60` 严重 |
| `主战意` | 主队战意，`0` 普通，`0.30` 偏强，`-0.30` 偏弱 |
| `客战意` | 客队战意，`0` 普通，`0.30` 偏强，`-0.30` 偏弱 |

## 公共设置

| 字段 | 简单理解 |
| --- | --- |
| `联赛` | 可以写英超、意甲、日职、巴甲等 |
| `平均总进球` | 这个联赛大概每场几个球，一般 `2.20` 到 `3.20` |
| `主场优势` | 普通填 `0.10` 到 `0.15` |
| `波动` | 比赛容易出大比分就填高一点，比如 `0.70`；保守联赛填 `0.35` |

## 你只想先试一下

什么都不改，直接点击 `分析12场`。  
它会用默认的 12 场假比赛跑一遍，让你看到模型输出长什么样。
