# 比分分析流程 v2

目标：每场只输出一个比分，但每场都必须独立分析，不能套模板。流程按“数据先校验，再判断剧本，最后全比分池排除”执行。

## 1. 数据获取顺序

每场比赛至少拉三类数据：

| 顺序 | 数据源 | 用途 |
| --- | --- | --- |
| 1 | 雷速体育 | 确认赛程、开赛时间、联赛轮次、排名、交锋、近期走势入口 |
| 2 | 官方联赛/俱乐部/权威新闻 | 确认积分形势、争冠/升级/保级、是否最后一轮、伤停和轮换 |
| 3 | 赔率/数据网站 | 获取 1X2、让球、大小球、市场预期进球、精准比分赔率 |
| 4 | 数据对照 | 对比至少两个外部来源，防止单站数据错位或过期 |

如果比赛已经开赛，只能明确标记“赛中信息”，不能混入赛前模型复盘。

## 2. 积分战意校验

排名不能直接等于战意。每场先回答四个问题：

| 问题 | 影响 |
| --- | --- |
| 赢球是否改变冠军、升级、欧战、保级、附加赛？ | 决定 `table_pressure` |
| 平局是否够用？ | 决定 `draw_sufficient` 和低比分平局权重 |
| 是否需要净胜球？ | 决定 `big_win_need` 和 3球以上比分是否入池 |
| 是否已锁定目标或已降级？ | 决定 `settled`、轮换和深盘不穿风险 |

最后一轮必须先算积分和净胜球，再看赔率。

## 3. 盘口资金层

深盘单独分型：

| 类型 | 判断 | 比分池 |
| --- | --- | --- |
| 真深盘 | 强队有战意、进攻强、弱队防线崩、盘口低水不退 | `3-0`、`4-0`、`4-1`、`5-0` |
| 赢不穿 | 强队优势真，但战意/轮换/效率不足 | `1-0`、`2-0`、`2-1` |
| 诱上盘 | 强队热度高，盘口深但赔率不配合 | `1-1`、`2-1`、`2-2` |
| 深盘反穿 | 弱队战意强或强队已锁目标 | `0-1`、`1-2`、`0-2`、`2-2` |

资金层只作为市场行为，不当玄学，也不能当比赛结果原因。机构设盘的作用是把可能结果包装成盈利结构：利用大众惯性、名气队偏见、深盘恐惧或热门幻想来分流资金，再通过水位调整风险。

执行规则：

| 判断 | 处理 |
| --- | --- |
| 球队事实侧和盘口方向一致 | 盘口只增强剧本信号，不直接替代比分判断 |
| 盘口热但球队事实侧弱 | 降低市场预期进球和盘口方向权重，进入 `market independence` |
| 深盘但支撑不足 | 先按诱上盘/赢不穿处理，再让 `0-1/1-1/1-2/2-0/2-1` 竞争 |
| 大众名气队低赔 | 必须用 xG、战意、伤停、赛程验证，不能自动给正路打穿 |
| 盘口反复调水 | 只解释资金流，不等于赛果改变 |

## 4. 每场六路出口

每场都要同时考虑六个出口，然后只选最强路径：

| 出口 | 典型比分 |
| --- | --- |
| 正路打穿 | `3-0`、`3-1`、`4-0`、`4-1`、`5-0` |
| 热门不穿 | `1-0`、`2-0`、`2-1` |
| 平局 | `0-0`、`1-1`、`2-2`、`3-3` |
| 冷门 | `0-1`、`1-2`、`0-2`、`1-3` |
| 大球互爆 | `3-2`、`2-3`、`4-2`、`2-4`、`4-3` |
| 小球锁死 | `0-0`、`1-0`、`0-1` |

禁止先决定“今天要几场冷门/几场大球”。批量结构只能用于检查是否过度重复，不能替代单场判断。

## 5. 全家比分池

默认 `scorebook` 已扩展到 41 个比分，覆盖常见平局、窄胜、零封、单边打穿、互爆和极端崩盘：

每场必须先完整扫一遍雷速常见比分盘面：

```text
主胜：1-0 2-0 2-1 3-0 3-1 3-2 4-0 4-1 4-2 5-0 5-1 5-2
平局：0-0 1-1 2-2 3-3
客胜：0-1 0-2 1-2 0-3 1-3 2-3 0-4 1-4 2-4 0-5 1-5 2-5
```

扫完这 28 个明确比分后，再看 `胜其他/平其他/负其他` 代表比分，例如 `4-3/3-4/4-4/5-3/3-5/6-0/0-6/6-1/1-6/6-2/2-6/7-0/0-7`。最终比分可以落在任何一个有信号支撑的分支，但不能跳过盘面直接凭感觉选 `1-1/2-1/2-2`。

```text
0-0
1-0 0-1 1-1
2-0 0-2 2-1 1-2 2-2
3-0 0-3 3-1 1-3 3-2 2-3 3-3
4-0 0-4 4-1 1-4 4-2 2-4 4-3 3-4 4-4
5-0 0-5 5-1 1-5 5-2 2-5 5-3 3-5
6-0 0-6 6-1 1-6 6-2 2-6
7-0 0-7
```

如果需要完整网格，用 `--score-profile full`。

## 6. 输出要求

内部分析输出：

| 字段 | 内容 |
| --- | --- |
| `资金/剧本` | 真热、假热、深盘诱上、保级抢命、平局够用等 |
| `排除后的比分层` | 为什么排除舒服比分、极端比分或冷门比分 |
| `唯一比分` | 只留一个最终比分 |

公开输出可以只保留比赛和比分，但内部必须留原因，便于赛后复盘。

## 7. 防缩口规则

模型不能只在 `1-1`、`2-1`、`2-2`、`3-1` 这些舒服比分里打转。每场最终选择前必须再过一次脚本通道挑战：

| 通道 | 触发条件 | 允许挑战的比分 |
| --- | --- | --- |
| 小球锁死 | 低 xG、天气拖球、双方平局够用、资金偏小 | `0-0`、`1-0`、`0-1` |
| 零封 | 一方进攻低迷、对手防守稳定、大小球不支持互爆 | `2-0`、`0-2`、`3-0`、`0-3` |
| 单边打穿 | 真深盘、净胜球需求、弱队已崩或已无目标 | `3-0`、`4-0`、`5-0`、`0-3`、`0-4` |
| 热门不穿 | 深盘有热度但战意/轮换/效率不足 | `1-0`、`2-0`、`2-1`、`1-1` |
| 冷门 | 假热、弱队抢命、强队锁定目标或伤停明显 | `0-1`、`1-2`、`0-2`、`1-3` |
| 互爆 | 联赛波动高、双方防线差、大球热度和 xG 同向 | `3-2`、`2-3`、`4-2`、`2-4`、`4-3` |

如果当前第一名比分属于宽泛公众比分，挑战门槛必须下降；如果挑战比分是极端比分但没有战意、盘口或 xG 支撑，必须拦截。这个规则的目标不是强行反大众，而是防止模型自动缩回最安全的比分。

强制执行层：触发 `假热热门`、`深盘诱上`、`真深盘`、`末轮混乱`、`保级抢命`、`崩盘风险`、`强平局阶梯` 任一强信号时，模型必须进入 `forced exit gate`。进入后，`1-1/2-1/2-0/3-1` 不能直接作为最终答案，必须让冷门、零封、单边打穿、热门不穿、互爆或低比分锁死重新竞争。候选比分仍要通过概率底线、结构分、路线支撑和冲突惩罚，防止为了反大众而乱出极端比分。

批量结构审计：一次分析 8 场以上时，要统计最终比分结构。如果 `1-1/2-1/2-0/2-2/3-1` 等舒服区过多，进入 `slate structure audit`。审计只替换两类比赛：一是单场本身有假热、深盘、保级、末轮、崩盘信号；二是非舒服候选的路线支撑已经足够但被基础概率压下去。真热强队、xG 和盘口同向的比赛不强行反。

批量大球审计：防缩口不能变成全大球，也不能从全大球直接缩成全小球。一次分析 8 场以上时，还要统计 `4+` 总进球比分。`slate goal balance audit` 的目标比例由整组 `xG/联赛波动/over热度/末轮/保级/真深盘/互爆压力` 动态决定；高压组可以保留更多大球，低压组才压低。审计优先降掉支撑弱的 `3-2/2-3/4-1/1-3/4-2`，让 `2-1/1-2/3-0/0-3/2-0/0-2/1-1/0-0` 重新竞争。末轮混乱、真深盘、保级抢命、强互爆或高 xG 同向时，大球不机械砍掉。

单场形态仲裁：最终比分不能只按最高概率排序再微调。先识别比分形态，再让形态按信号竞争：极端零封 `4-0/0-4/5-0/0-5` 看真深盘、净胜球需求、弱队低 xG、弱队崩盘；单边带丢球 `4-1/1-4/5-1/1-5` 看强队持续进攻和对手防线松散；互爆 `4-2/2-4` 看高 xG、波动和双方进球能力；高平 `3-3` 看平衡盘、末轮混乱和互爆共振；小球冷门 `0-1/1-0/0-2/2-0` 看假热热门、低总进球、under 热度和弱队战意。形态仲裁必须保护已成立的强单边、强崩盘和强冷门剧本，防止把比分乱抬成大球。

结果剧本仲裁：形态之前先定比赛剧本，不能把所有比赛都套成盘口正路，也不能为了反盘口全出冷门。九类剧本如下：

| 剧本 | 典型比分 | 核心信号 |
| --- | --- | --- |
| 小球正路 | `1-0`、`2-0` | 强队真实优势、总进球低、under 热、节奏慢 |
| 大球正路 | `2-1`、`3-1` | 正路方向成立、总进球抬高但不是互爆或打穿 |
| 大球互爆正路 | `3-2`、`4-2` | 正路方向 + 双方 xG 都够 + 联赛波动高 |
| 大球打穿正路 | `3-0`、`4-0`、`4-1`、`5-1` | 真深盘、净胜球需求、弱队低 xG 或崩盘 |
| 小球平局 | `0-0`、`1-1` | 平局够用、低总进球、天气/节奏拖慢 |
| 大球平局 | `2-2`、`3-3` | 平衡盘、高波动、末轮混乱、双方都必须攻 |
| 小球冷门 | `0-1`、`0-2`、`1-2` | 假热热门、低总进球、弱队战意、热门不穿 |
| 大球互爆冷门 | `2-3`、`1-2` | 冷门方向 + 双方都有进球能力 + over/波动支撑 |
| 大球打穿冷门 | `0-3`、`1-3`、`1-4` | 热门崩盘、弱队抢命、盘口诱上、末轮心态断裂 |

## 8. 末轮极端分化规则

末轮、争冠组最后阶段、保级组最后阶段不能按普通联赛均值处理。先填 `is_final_round=true`，再判断四个收官变量：

| 字段 | 何时提高 | 影响比分 |
| --- | --- | --- |
| `endgame_chaos` | 多队同分、抢欧战/保级、盘面分歧大 | 放大 `3-3`、`2-3`、`3-2`、`4-2`、`2-4` |
| `celebration_risk` | 已夺冠/已升级/主场谢幕，强队仍可能攻但防守松 | 放大 `4-1`、`5-1`、`5-0`，而不是停在 `3-1` |
| `collapse_risk` | 无目标、连续丢球、防线伤停、末轮心态崩 | 放大 `0-3`、`1-3`、`0-4`、`1-4` |
| `survival_pressure` | 保级/附加赛抢命，平局没用，必须主动赢 | 放大 `3-0`、`4-1`、`5-1`、`6-1`，也放大被反击后的 `3-2`、`2-3` |
| `draw_sufficient + under_heat` | 双方平局够用、强队无目标、大小球偏小 | 保留 `0-0`、`1-0`、`0-1` |

复盘截图里的 `5-1、3-3、2-3、1-3、0-3、0-0、2-0` 属于同一类问题：不是要全大或全冷，而是收官战会把普通比分向两端拉开。模型现在会先判断收官变量，再允许这些比分挑战 `1-1、2-1、2-2、3-1`。

## 9. 保级抢命队进攻爆发

保级队不是一定龟缩。末轮平局没用时，弱队会把比赛打成高压进攻，尤其对手已经无目标、轮换或防线松散时，比分会从普通 `2-1` 直接拉到 `3-0、4-1、5-1、6-1`。

执行规则：

| 判断 | 处理 |
| --- | --- |
| 保级/附加赛必须赢 | `survival_pressure=0.75..1.00`，不能只填普通 `motivation` |
| 对手已无目标或崩盘 | 对手 `settled=true` 或 `collapse_risk>=0.45` |
| 盘口仍把抢命队做成受让 | 提高 `bookmaker_trap_risk`，允许反市场打穿 |
| 抢命队领先后继续进攻 | 不自动收成 `2-0/2-1`，保留 `3-0/4-1/5-1/6-1` |

这条规则专门针对复盘里的菲尔特 `3-0`、比勒费尔德 `6-1` 这种结果：它不是随机大球，而是“生死压力 + 对手松散/崩盘 + 市场低估主队进攻”的组合。
