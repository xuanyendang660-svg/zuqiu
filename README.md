# 足球比分模型 v2：数据驱动基线

v2 从空白重建。它不允许人工填写“冷门权重”“打穿权重”或为了避开大众比分而改答案。

## 当前目标

先证明以下最小能力，再谈赛前预测：

1. 正常比分、低事件、互爆、热门打穿、冷门打穿必须由历史样本学习。
2. `1-5`、`6-1` 等极端比分在模型结构中具有真实胜出资格，而不是只写进备用池。
3. 所有复杂模型必须与三个基准比较：独立泊松、Dixon-Coles、市场中心落点。
4. 预测冻结后，用户反馈“太顺”“太模板”不能触发修改。
5. 回测必须报告精确比分、Top-K、方向、比分形态、负对数似然和极端尾部召回率。

## v2 包含

- 完整 0–7 比分网格；
- 泊松与 Dixon-Coles 基准；
- 数据训练的比分形态分类器；
- 数据训练的精确比分分类器；
- 分层概率协调：形态概率与具体比分概率保持一致；
- 冷门打穿/热门打穿/互爆/低事件标签；
- 赛前冻结与硬证据解锁；
- 自动测试，包括模型必须能够在合成的客队崩盘场景中选出 `1-5`。

## 明确边界

这只是可运行、可测试的数据建模底座。没有真实历史数据和样本外回测前，不声称它能稳定预测大奖比分。

## 安装与测试

```bash
python -m pip install -e ".[dev]"
ruff check src tests
pytest
```

## 输入特征原则

训练数据可以包含：

- 去水后的 1X2、让球、大小球、BTTS；
- 开盘到临场的变化；
- 对手修正 xG/xGA、射正、重大机会；
- 领先/落后状态表现；
- 中卫、后腰、门将、核心攻击手缺阵；
- 休息天数、旅行、长间歇、赛事任务；
- 主客场及联赛标识。

模型不会在代码中写死这些变量的权重，权重由训练样本学习。
