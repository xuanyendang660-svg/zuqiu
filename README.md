# 全球足球唯一精准比分模型

这是一套用于赛前分析的足球唯一比分模型。目标不是给多个候选比分，而是每场比赛在完整分析后只输出一个最终比分。

当前版本重点优化了三件事：

- 每场单独分析，不套“全冷门、全大球、全正路”的模板。
- 默认比分池扩展到 41 个常用比分，覆盖零封、小球、互爆、冷门、单边打穿和极端崩盘。
- 固定逐项扫描比分盘面：`1-0/2-0/2-1/3-0/3-1/3-2/4-0/4-1/4-2/5-0/5-1/5-2/0-0/1-1/2-2/3-3/0-1/0-2/1-2/0-3/1-3/2-3/0-4/1-4/2-4/0-5/1-5/2-5`。
- 新增积分战意、深盘、资金热度、庄家诱导和剧本字段，让这些因素能进入模型计算。
- 新增市场独立层：盘口和水位不是比赛结果原因，只作为机构盈利、资金流向和大众惯性引导信号；当球队事实侧和盘口方向冲突时，盘口会被降权。
- 新增防缩口选择器，避免最终阶段又缩回 `1-1`、`2-1`、`2-2`、`3-1` 这类舒服比分。
- 新增末轮极端分化逻辑，用 `is_final_round`、`endgame_chaos`、庆典风险和崩盘风险处理 `5-1`、`3-3`、`2-3`、`1-3`、`0-3`、`0-0` 这类收官比分。
- 新增保级抢命队进攻爆发通道，用 `survival_pressure` 处理弱队必须赢时的 `3-0`、`4-1`、`5-1`、`6-1`。

## 默认比分池

```text
0-0
1-0 0-1 1-1
2-0 0-2 2-1 1-2 2-2
3-0 0-3 3-1 1-3 3-2 2-3 3-3
4-0 0-4 4-1 1-4 4-2 2-4 4-3 3-4 4-4
5-0 0-5 5-1 1-5 5-2 2-5 5-3 3-5
6-0 0-6 6-1 1-6 6-2 2-6
7-0 0-7
```

如需完整网格，可以用 `--score-profile full`。

## 分析流程

每场先做数据校验，再跑比分：

1. 用雷速确认赛程、时间、排名、交锋、近况入口。
2. 用官方联赛/俱乐部/权威新闻确认积分、净胜球、保级/升级/争冠/轮换。
3. 用赔率和数据网站补 1X2、让球、大小球、精准比分赔率、市场预期进球。
4. 先逐项过固定比分盘面，再过胜其他/平其他/负其他代表比分，不能只挑舒服比分。
5. 单场过九类剧本：小球正路、大球正路、大球互爆正路、大球打穿正路、小球平局、大球平局、小球冷门、大球互爆冷门、大球打穿冷门。
5. 全比分池逐层排除，最后只留一个比分。

详细流程见 [docs/analysis_workflow_v2.md](docs/analysis_workflow_v2.md)。

## 强制出口

新版选择器增加 `forced exit gate`。当假热热门、深盘诱上、真深盘、末轮混乱、保级抢命、崩盘风险或强平局阶梯触发时，模型不能继续缩回 `1-1`、`2-1`、`2-0`、`3-1` 这类舒服区，必须在冷门、零封、单边打穿、热门不穿、互爆或低比分锁死里重新选一个有支撑的出口。

这不是强行反大众。若真实强队热度、xG、战意和盘口都同向，`forced exit gate` 不会启动；若启动，候选比分仍必须过概率、结构分、冲突惩罚和路线支撑门槛，防止乱飞极端比分。

批量模式还增加 `slate structure audit`。当 10-12 场结果里舒服比分占比过高时，会重审结构最弱的舒服比分，把有支撑的 `0-3/3-0/1-4/4-1/3-2/2-3/3-3` 等尾部分支拉回竞争池；真热强队批量不会被强行反掉。

同时增加 `slate goal balance audit`。如果批量结果里 4+ 球比分过多，会优先降掉支撑弱的大球，改由小球、零封、低比分冷门或热门不穿承接；但目标比例不是固定的，会按整组 `xG/联赛波动/over热度/末轮/保级/真深盘/互爆压力` 动态抬高或压低。末轮强支撑、真深盘、保级抢命和强互爆不会被机械砍掉。

单场选择器还增加 `shape arbitration`。它不是按比例硬塞极端比分，而是给 `4-0/0-4/5-0/0-5`、`4-1/1-4/5-1/1-5`、`4-2/2-4`、`3-3`、小球冷门各自设置独立信号；只有真深盘、净胜球需求、末轮崩盘、互爆高压、假热热门、低总进球等条件成立时，才允许这些比分越过舒服区。

同时增加 `result script arbitration`，先把每场比赛拆成九类剧本再选比分：`small_normal` 小球正路、`big_normal` 大球正路、`big_exchange_normal` 大球互爆正路、`big_cover_normal` 大球打穿正路、`small_draw` 小球平局、`big_draw` 大球平局、`small_cold` 小球冷门、`big_exchange_cold` 大球互爆冷门、`big_cover_cold` 大球打穿冷门。盘口只提供一个市场视角，不直接决定剧本；模型会用 xG、总进球线、资金热度、真假热门、战意、保级压力、末轮崩盘和双方进球能力重新仲裁。

## 边界

当前项目是本地可执行模型骨架，不包含稳定自动采集器。实际使用时仍需要先从雷速、官方积分形势和外部赔率/数据网站整理字段，再交给模型跑唯一比分。
